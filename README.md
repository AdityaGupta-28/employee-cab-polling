# employee_cab_pooling

Smart Employee Transportation and Cab Pooling System.

## Architecture & Locked-in Stack
- **Backend:** Java 21, Spring Boot 3.3.4 (Web, Security, Data JPA, Validation, Actuator)
- **Database:** PostgreSQL
- **Frontend:** React + TypeScript + Vite
- **Auth:** JWT (Spring Security)
- **Routing Engine:** OSRM / OpenRouteService
- **Build Tool:** Maven

## Phase 1
- Project initialized with Spring Initializr specifications:
  - Java 21 & Spring Boot 3.3.4
  - Dependencies: Web, Data JPA, Security, Validation, Actuator, PostgreSQL Driver, Lombok, Test starters
  - Package: `com.cabpooling.employeecabpooling`
